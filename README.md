# ORBITAL

[▶ ブラウザーで遊ぶ（スマホ・PC）](https://tanekoh923.github.io/orbital-shooter/)

グラディウスに着想を得た、オリジナルの横スクロールシューティングです。
`index.html` をブラウザーで開くだけで遊べます。ビルド・インストール不要です。

## スマホで遊ぶ

公開されたゲームURLを Safari / Chrome で開いて「出撃する」をタップします。横向きがおすすめです。

- 左の移動パッドを倒して移動。画面上のドラッグでも、指を動かした分だけ移動できます
- 射撃は初期状態で自動。手動で撃つ場合は AUTO FIRE をオフにし、FIRE を押し続けます
- カプセルで強化候補を選び、右の POWER UP / 装備ボタンで取得
- 「ゲームを大きく」でゲーム画面と操作パッドをまとめて表示。「通常表示」で設定画面へ戻ります
- 一時停止／再開は画面のボタンから操作できます。画面回転・アプリ切り替え時には自動で一時停止します
- マルチタッチ対応。移動パッドを押しながら射撃や装備ができます

スマホのローカルファイル閲覧には制約があるため、GitHub PagesなどのHTTPS公開URLから開いてください。

- 移動: 矢印キー / WASD（タッチでは画面をドラッグ）
- 射撃: Space / Z。AUTO FIRE は初期状態で有効
- 強化: カプセルを拾うと選択位置が進むので、X で装備
- 初期の強化順: SPEED → MISSILE → DOUBLE → LASER → OPTION → SHIELD
- 一時停止 / 再開: P / Escape
- 出撃 / リトライ: Enter
- 全5ステージ。各ステージ約60〜70秒でボスが登場
- ステージ1〜4のボス撃破後、Enter /「次のステージへ」で進行
- ステージ間はスコア・装備・パワーアップ選択を引き継ぎ、耐久が1回復（上限3）
- ステージ5のボスを倒すと ALL CLEAR。ゲームオーバー後はステージ1から再挑戦
- 耐久は3。被弾後は一時無敵。画面下部の地形にも当たり判定あり
- ベストスコアはブラウザーに保存。効果音は SOUND ボタンで切り替え

外部フォントが取得できない場合も代替フォントで動作します。

## 出撃設定

画面上部の「出撃設定」を開き、機体・防御装備・ゲージの順番を変更できます。
ゲージの各枠で装備を選ぶと、同じ装備があった枠と入れ替わります。
設定は任務中（ポーズ中・ステージ間も含む）は固定。ゲームオーバー／全ステージクリア後に再設定できます。

| 機体 | DOUBLE | LASER | MISSILE |
| --- | --- | --- | --- |
| VECTOR | 斜め射撃 | 直進、Lv.2で貫通 | 下向き・地表追従 |
| TEMPEST | 後方射撃 | 波動弾 | 上下2方向 |
| LANCER | 扇状射撃 | 範囲炸裂弾 | 敵への追尾 |
| PRISM | 上下端で反射する弾 | 分岐、Lv.2で貫通 | 直進・範囲炸裂 |

MISSILE・DOUBLE・LASER は同じ装備を2回取得すると Lv.2 になります。
DOUBLE と LASER は同時使用不可。別武器へ切り替えても取得済みのレベルを保持し、再取得で選択し直せます。
OPTION は最大4機で、自機と同じ武装で攻撃します。SPEED は最大3段階です。
最大強化済みの使用中装備は再取得できず、選択位置は保持されます。

| 防御装備 | このゲームでの効果 |
| --- | --- |
| SHIELD | 前からの攻撃を12回防ぐ。背後・上下・地形には無効 |
| GUARD | 上下からの攻撃を合計3回防ぐ。残っている間は地形接触によるダメージなし |
| FORCE FIELD | 全方向からの攻撃を3回防ぐ。地形には無効 |
| LIMIT | 装備した瞬間から3秒間、敵・弾・地形に対して無敵。ポーズ中は時間停止 |

防御装備は効果が切れてから再装備できます。機体・ゲージ順・武器レベル・防御の残量も次のステージに引き継ぎます。

グラディウス外伝のゲージ編集、機体別武装、2段階強化、4種類の防御を参考にした独自アレンジです。
機体名・武器の軌道や威力・耐久制・地形は本作独自で、原作の完全再現ではありません。
参考: [Konami『Gradius Collection』取扱説明書の外伝セクション（印刷ページ16〜20）](https://www.gamesdatabase.org/Media/SYSTEM/Sony_PSP/Manual/formated/Gradius_Collection_-_2006_-_Konami.pdf)、[Gradius Gaiden 攻略資料](https://gamefaqs.gamespot.com/ps/197466-gradius-gaiden/faqs/24943)。
