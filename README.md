# ORBITAL

[▶ ブラウザーで遊ぶ（スマホ・PC）](https://tanekoh923.github.io/orbital-shooter/)

グラディウスに着想を得た、オリジナルの横スクロールシューティングです。
`index.html` をブラウザーで開くだけで遊べます。ビルド・インストール不要です。

## スマホで遊ぶ

公開されたゲームURLを Safari / Chrome で開いて「出撃する」をタップします。横向きがおすすめです。

- 左の移動パッドを倒して移動。画面上のドラッグでも、指を動かした分だけ移動できます
- 射撃は初期状態で自動。手動で撃つ場合は AUTO FIRE をオフにし、FIRE を押し続けます
- カプセルで強化候補を選び、右の POWER UP / 装備ボタンで取得
- 「ゲームを大きく」でゲーム画面と操作パッドをまとめて表示。「通常表示」で設定画面へ戻ります
- 一時停止／再開は画面のボタンから操作できます。画面回転・アプリ切り替え時には自動で一時停止します
- マルチタッチ対応。移動パッドを押しながら射撃や装備ができます

スマホのローカルファイル閲覧には制約があるため、GitHub PagesなどのHTTPS公開URLから開いてください。

- 移動: 矢印キー / WASD（タッチでは画面をドラッグ）
- 射撃: Space / Z。AUTO FIRE は初期状態で有効
- 強化: カプセルを拾うと選択位置が進むので、X で装備
- 初期の強化順: SPEED → MISSILE → DOUBLE → LASER → OPTION → SHIELD
- 一時停止 / 再開: P / Escape
- 出撃 / リトライ: Enter
- 全5ステージ。各ステージ約60〜70秒でボスが登場
- ステージ1〜4のボス撃破後、Enter /「次のステージへ」で進行
- ステージ間はスコア・装備・パワーアップ選択を引き継ぎ、耐久が1回復（難易度ごとの上限まで）
- ステージ5のボスを倒すと ALL CLEAR。ゲームオーバー後は最初から出撃、またはその面の開始地点から再開
- 耐久はNORMAL／HARDで3、EASYで4。被弾後は一時無敵。地面・天井・障害物にも当たり判定あり
- 難易度別ベストスコア・練習の解放状況・出撃設定・ステージ開始時の進行をブラウザーに保存。効果音は SOUND ボタンで切り替え

外部フォントが取得できない場合も代替フォントで動作します。

## 出撃設定

画面上部の「出撃設定」を開き、任務・難易度・機体・防御装備・ゲージの順番を変更できます。
ゲージの各枠で装備を選ぶと、同じ装備があった枠と入れ替わります。
設定は任務中（ポーズ中・ステージ間も含む）は固定。ゲームオーバー／全ステージクリア後に再設定できます。

### 練習と途中再開

- **全5ステージ**：1面から新しく出撃したプレイは、選んだ難易度のベストスコアに記録します。
- **ステージ練習**：解放済みの面を標準装備から練習。ボス撃破でその練習を終了します。
- **ボス練習**：道中を飛ばし、レーザーLv.2・OPTION2機などの標準装備でボスへ挑戦します。
- 最初から1面と1面ボスを練習できます。本番で面をクリアすると、次の面とそのボス練習が解放されます。
- 練習はベストスコアや本番の進行へ加算されません。本番の保存進行を残したまま練習できます。
- 本番では各面の開始時にスコア・装備・強化選択を保存します。「このステージから再開」や設定欄の再開ボタンで復帰できます。ブラウザーを開き直しても、保存した面の開始地点から再開できます。
- 途中再開では耐久を回復し、ステージ開始時の装備に戻ります。HUDに **CONTINUE** を表示し、参考スコアとして扱います。

### 難易度

| 難易度 | 遊び心地 |
| --- | --- |
| EASY | 耐久4。敵弾が遅く、突進の予告が長い。カプセルも拾いやすい |
| NORMAL | 標準の速度・攻撃間隔・耐久3 |
| HARD | 敵弾が速く、敵の攻撃間隔が短い。ボスも強化される |

難易度ごとに記録を分けています。既存のベストスコアはNORMALへ引き継ぎます。

| 機体 | DOUBLE | LASER | MISSILE |
| --- | --- | --- | --- |
| VECTOR | 斜め射撃 | 直進、Lv.2で貫通 | 下向き・地表追従 |
| TEMPEST | 後方射撃 | 波動弾 | 上下2方向 |
| LANCER | 扇状射撃 | 範囲炸裂弾 | 敵への追尾 |
| PRISM | 上下端で反射する弾 | 分岐、Lv.2で貫通 | 直進・範囲炸裂 |

MISSILE・DOUBLE・LASER は同じ装備を2回取得すると Lv.2 になります。
DOUBLE と LASER は同時使用不可。別武器へ切り替えても取得済みのレベルを保持し、再取得で選択し直せます。
OPTION は最大4機で、自機と同じ武装で攻撃します。SPEED は最大3段階です。
最大強化済みの使用中装備は再取得できず、選択位置は保持されます。

| 防御装備 | このゲームでの効果 |
| --- | --- |
| SHIELD | 前からの攻撃を12回防ぐ。背後・上下・地形には無効 |
| GUARD | 上下からの攻撃を合計3回防ぐ。残っている間は地形接触によるダメージなし |
| FORCE FIELD | 全方向からの攻撃を3回防ぐ。地形には無効 |
| LIMIT | 装備した瞬間から3秒間、敵・弾・地形に対して無敵。ポーズ中は時間停止 |

防御装備は効果が切れてから再装備できます。機体・ゲージ順・武器レベル・防御の残量も次のステージに引き継ぎます。

グラディウス外伝のゲージ編集、機体別武装、2段階強化、4種類の防御を参考にした独自アレンジです。
機体名・武器の軌道や威力・耐久制・地形は本作独自で、原作の完全再現ではありません。
参考: [Konami『Gradius Collection』取扱説明書の外伝セクション（印刷ページ16〜20）](https://www.gamesdatabase.org/Media/SYSTEM/Sony_PSP/Manual/formated/Gradius_Collection_-_2006_-_Konami.pdf)、[Gradius Gaiden 攻略資料](https://gamefaqs.gamespot.com/ps/197466-gradius-gaiden/faqs/24943)。

## 敵と地形

敵は8種類。編隊・攻撃・耐久・得点・形状が異なり、ステージごとに出現順も変わります。

| 敵 | 攻略のポイント |
| --- | --- |
| 偵察機 | 直進する編隊。橙色の機体はカプセルを落とす |
| 波状編隊 | 上下に波を描く。進路に合わせて狙う |
| 突撃機 | 照準線で予告した位置へ突進。予告後に移動して避ける |
| 地上砲台 | 地面に沿って配置。下向きミサイルが有効 |
| 天井砲台 | 洞窟・廃墟・要塞の天井に配置。上方向への攻撃が有効 |
| 装甲機 | 前面への通常弾を軽減。レーザー・ミサイル・後方攻撃が有効 |
| 小型空母 | 偵察機を放出する。優先して撃破すると敵数を抑えられる |
| 回転機雷 | 間隔を空けて6方向の弾を放つ |

| ステージ | 地形・仕掛け | ボス |
| --- | --- | --- |
| 1 蒼の宙域 | 開けた航路と起伏。基本の敵を順番に導入 | 幅広い母艦・扇状弾 |
| 2 灼熱の小惑星帯 | 溶岩の山、岩、予告付き噴出口 | 槍型機・予告突進・3連狙い撃ち |
| 3 氷の星雲 | 上下の氷壁がうねる洞窟 | 結晶型機・周回移動・放射弾 |
| 4 翠の廃墟 | 天井と床から伸びる石柱 | 遺跡の守護機・隙間のある弾壁 |
| 5 最終防衛線 | 要塞の段差と予告付きゲート | 回転する中枢・複合弾幕 |

黄橙色の輪郭・照準線は攻撃の予告です。敵弾は白い縁取りのある赤紫色、ミサイルは金色、カプセルは青い六角形で見分けられます。自機の白い点は当たり判定の中心です。

狭い通路・ゲート・噴出口の近くでは編隊と弾の間隔を調整し、突破後に装備カプセルを配置します。地形には通れる幅を確保し、ボス戦の前には開けた空間へ移ります。地形や敵の配置は本作独自の設計です。

全ボスに2つの形態とコアの開閉があります。**コアが光っている間**に狙うとダメージが入り、閉じている間は周囲の部位を狙えます（槍型機には独立した部位はありません）。残り耐久が半分以下、または周囲の部位をすべて破壊すると、第2形態への予告が入ります。予告中は弾を消去し、退避の時間を確保します。

OPTIONの追従は経過時間を基準にし、30fpsと60fpsで追従の速さが大きく変わらないようにしています。

`world.js` は地形、`enemies.js` は敵、`encounters.js` は地形と編隊の組み合わせ、`bosses.js` はボスの形態・部位・攻撃、`records.js` は保存データの検証と移行を担当します。弾は地形で遮られ、地表を走るミサイルは地面の起伏を追従します。
